# AI Workflow Demo

This workflow explains an AI product through observable states: structured input, running steps, inspectable output, and explicit human approval. It avoids magical before/after framing.

## Expected rhythm

| Time | Beat | Review intent |
| --- | --- | --- |
| 0.0-1.5s | Literal workflow promise | State what the system produces and how it is reviewed. |
| 1.5-4.5s | Structured brief | Brand, audience, and output requirements remain readable. |
| 4.5-8.0s | Visible execution | Progress reads left-to-right; status colors are not the only signal. |
| 8.0-11.0s | Human review | The approve action is visible but not clicked before the result is inspectable. |
| 11.0-12.0s | Trust-oriented close | Emphasize deliberate approval rather than autonomous publishing. |

The fictional Relay UI and all embedded preview artwork are original MIT-licensed repository assets.
