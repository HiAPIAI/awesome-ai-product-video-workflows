# Review checklist

- [ ] Confirm the brief, running workflow, and review surface appear in causal order.
- [ ] Confirm progress is understandable without relying only on green, yellow, or red.
- [ ] Confirm the workflow callout does not obscure step names or status labels.
- [ ] Confirm the generated output remains inside the deterministic review UI.
- [ ] Confirm the approval click happens only after the output is readable.
- [ ] Confirm no copy implies automatic publication or guaranteed model quality.
- [ ] Confirm no API key, task ID, customer prompt, or private asset appears.
- [ ] Record deviations before changing workflow status from `spec-only`.
