# Mobile Onboarding

This workflow treats onboarding as a value-delivery sequence, not a tour. Three screens establish the promise, collect two meaningful preferences, and reveal a useful first plan.

## Expected rhythm

| Time | Beat | Review intent |
| --- | --- | --- |
| 0.0-1.0s | Outcome-led hook | Avoid generic welcome language. |
| 1.0-3.3s | One clear start action | The primary button remains thumb-readable. |
| 3.3-5.7s | Two preference choices | Selection order is understandable without narration. |
| 5.7-8.0s | First useful result | The plan card is the visual peak. |
| 8.0-10.0s | Outcome lockup | End on product value, not setup instructions. |

All three mobile screens are original fictional UI assets licensed under MIT.
