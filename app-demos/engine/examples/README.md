# Workflow examples

These five examples are source specifications and original fictional UI assets for the `demo-v1` contract.

| Example | Primary review question |
| --- | --- |
| [SaaS Feature Launch](saas-feature-launch/) | Is one feature connected to a readable product result? |
| [Mobile Onboarding](mobile-onboarding/) | Does the first-run story reach useful value without rushing? |
| [AI Workflow Demo](ai-workflow-demo/) | Are input, execution, output, and human approval visible? |
| [Before / After Comparison](before-after-comparison/) | Are both states matched closely enough for an honest comparison? |
| [Vertical Social Feature](vertical-social-feature/) | Do the hook, tap, and result remain legible at phone size? |

Every directory contains `demo.yaml`, project-relative assets, an expected-rhythm table, and a full-video review checklist. All workflows remain `spec-only` until every declared output is rendered and reviewed from start to finish. Generated videos stay out of Git.
