# Vertical Social Feature

This seven-second workflow is built for a feed: one literal hook, one visible interaction, one finished state. It does not compress multiple unrelated features into the same short.

## Expected rhythm

| Time | Beat | Review intent |
| --- | --- | --- |
| 0.0-1.0s | Feature hook | The category is clear before the product screen appears. |
| 1.0-3.0s | Auto-caption interaction | The tap is visible and lands on the primary control. |
| 3.0-6.0s | Publish-ready result | Captions sit inside vertical platform safe margins. |
| 6.0-7.0s | Product lockup | One short product name, no competing CTA. |
