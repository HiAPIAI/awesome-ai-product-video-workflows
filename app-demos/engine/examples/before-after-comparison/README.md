# Before / After Comparison

This workflow keeps the product state, viewport, and information set matched so the redesign can be judged honestly. The comparison reveals hierarchy and action clarity, not an unrelated polished mockup.

## Expected rhythm

| Time | Beat | Review intent |
| --- | --- | --- |
| 0.0-1.0s | Literal comparison promise | Establish what changed. |
| 1.0-6.0s | Matched before/after reveal | Keep rows and invoice values aligned across both states. |
| 6.0-7.0s | After-state detail | Hold long enough to scan priority, owner, and action. |
| 7.0-8.0s | Outcome close | Describe the workflow benefit without inflated claims. |

Both states are original fictional Ledger UI assets licensed under MIT.
