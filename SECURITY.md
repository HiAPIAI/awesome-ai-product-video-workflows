# Security Policy

## Report a vulnerability

Please report security issues privately through GitHub's security advisory feature for this repository. Do not open a public issue containing credentials, private media, exploit details, or personal data.

## Repository safety

- Never commit API keys, tokens, cookies, passwords, or private `.env` files.
- Use placeholder domains and paths in public templates.
- Review product media, talent consent, and third-party licenses before sharing a case.
- Treat external repositories and installers as untrusted until their current code and dependencies are reviewed.
