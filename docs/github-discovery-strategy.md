# GitHub Repository Discovery Strategy

This repository is optimized for discovery and conversion **inside GitHub**. It does not depend on a companion website.

Verified: 2026-07-28

## Search intent

The repository targets people searching GitHub for:

- AI product video workflows
- product image to video ad
- ecommerce video ads
- AI product video generator
- UGC ads and creator-style product videos
- TikTok ads, Instagram Reels, and YouTube Shorts
- product photography and commercial hero visuals
- reusable agent skills for product marketing

These phrases are mapped naturally across the repository name, About description, topics, README opening, workflow titles, example names, and machine-readable package metadata. They are not repeated as hidden keyword blocks.

## Repository surfaces

### Name and About description

The repository name states the collection format and the main category. The About description explains the source-to-output path in one sentence and includes the principal user outcomes.

### Topics

The repository uses GitHub's full 20-topic allowance. Topics cover purpose, subject area, output formats, and user workflows rather than relying on model-specific names.

### README first screen

The default English README immediately shows:

1. the product-image-to-video transformation;
2. the intended users and outputs;
3. the Image2-generated reference visual;
4. a 30-second install command;
5. direct workflow and real-case entry points;
6. a clear reason to Star the repository.

The Chinese README mirrors the information architecture for Chinese-speaking visitors.

### Evidence and trust

The repository links to:

- a real generated UGC example with its limitation stated;
- reproducible production templates;
- six complete workflow documents;
- dated open-source research with license boundaries;
- automated validation and a public CI badge.

This gives visitors something useful before asking them to install or Star the project.

### Social preview

The 1280 × 640 JPEG uses a solid background and visually explains the three-stage transformation from source product image to commercial visual to vertical ad. The same image appears at the top of the README and is uploaded in GitHub repository settings.

## Validation

`npm run check` verifies:

- six distinct workflow intents and complete English/Chinese variants;
- README discovery phrases, single H1, hero image, quick start, and Star section;
- local Markdown links and descriptive image alt text;
- social-preview dimensions and file-size limit;
- source project license and adoption records;
- public template safety defaults;
- absence of common secret patterns.

GitHub search indexing and ranking can change over time. Repository activity, useful releases, links, forks, and legitimate Stars remain stronger long-term discovery signals than repeating keywords.
